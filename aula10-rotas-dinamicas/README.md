# Aula 10 - Rotas Dinâmicas com NestJS

Projeto desenvolvido durante o curso de desenvolvimento **Back-End com NestJS**.

## Sobre o projeto

Nesta aula foi desenvolvida uma API para consulta de jogos utilizando **NestJS**.

O projeto demonstra a utilização de rotas dinâmicas através do parâmetro `:id`.

## Tecnologias utilizadas

- Node.js
- NestJS
- TypeScript
- npm
- Git

## Funcionalidades

- Consulta de jogos por ID
- Rotas dinâmicas
- Parâmetros de URL
- `ParseIntPipe`
- `NotFoundException`
- Injeção de dependências
